Tool description is behavioral instruction(s), not documentation. It is not for human, it is for Claude to make a decision when to call the tool!

Tool description should answer next questions:
	- What domain does this tool operate in (domain)?
	- When should this tool be called (trigger conditions)?
	- What should this tool not be used for (exclusion)?
	- Does this tool have ordering constraints (Sequencing)?
